Africa 🦁

Africa is a SwiftUI iOS app designed to help users explore African wildlife through animal profiles, images, videos, and interactive map locations.

The app offers a clean dark-themed interface and allows users to browse animals, learn interesting facts, watch wildlife videos, explore photo galleries, and view the regions where different species are commonly found.

Features

Browse African animals in list and grid layouts

View detailed information about each animal

Explore high-quality wildlife image galleries

Watch animal videos with playback controls

View animal locations on an interactive map

Open external learning resources such as Wikipedia

Switch easily between Browse, Watch, Locations, and Gallery tabs

Clean, modern, and responsive SwiftUI interface

What I Learned

While building Africa, I learned how to create a complete multi-screen iOS application using SwiftUI.

This project helped me practise reusable components, list and grid layouts, navigation, tab-based interfaces, JSON data handling, image galleries, video playback, and interactive maps.

I also learned how typography, spacing, colours, icons, animations, and media content can work together to create a polished and engaging user experience.
